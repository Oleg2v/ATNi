# Two-minute demo script (Nutrition Data Hub — concept)

Open the prototype. The banner "Unofficial concept by Kikkey · Synthetic data · Not affiliated with or endorsed by ATNi" stays on every screen. Everything below runs offline after the first load.

| Time | Screen | What to say and do |
|---|---|---|
| 0:00 | Start | "Company user on a phone. Country, size, language — the `lang` attribute follows the switch." Click **Load sample answers** (or run the questionnaire: conditional questions 1.2, 2.2, 2.3; **Simulate offline** keeps saving on the device and syncs on **Back online**). |
| 0:20 | Results | "A letter and five topic letters. Marketing is C." Open **Why this score**: every answer, points, maximum, the formula, thresholds, methodology version and date. "Hidden questions don't count against you." |
| 0:40 | Roadmap | "Now / Next / Later, generated by 14 published rules. Every step says *because you answered …*. Filter by topic. Print or save as PDF." |
| 0:55 | Assistant | Click **Ask about my results**. Ask *Why did I get a C on marketing?* → answer built from the scores and recommendations with source chips. Ask *Is this porridge good for my diabetes?* → polite refusal. Ask the shipping-tariff question → "not found in published materials" → **Send to the hub team** → ticket number. Point at the footer line about the EU-hosted model. |
| 1:20 | Admin (role switcher → Methodology editor) → Methodology → v1.1 | "No developer needed." Change the score of *Yes* in question 2.1 from 5 to 2.5. The health panel turns red: *No recommendation for score 2.5 in question 2.1* and **Publish** is blocked; the message links to the field. Add the recommendation; the block clears. |
| 1:40 | Publish v1.1 | Open **Publish**: "Of 74 past assessments, N would have a different letter — they stay on v1.0 until the company assesses again", plus the line-by-line diff. Add a comment, publish. Journal gets the entry; the company's previous result still shows v1.0 and the same letter. |
| 1:55 | For evaluators | "Requirement → where in the prototype" table, what is real and what is simulated, the guided tour button for a self-run walkthrough. |

Fallbacks: **Reset demo** restores the synthetic data set. The guided tour (For evaluators → *Start the 2-minute guided tour*) covers the same path for a self-service reviewer.
